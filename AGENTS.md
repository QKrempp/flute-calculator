# AGENTS.md

## Objectif du projet

- Créer un calculateur d'emplacemment pour les trous d'une flûte en fonction des formules fournies dans [cet article](https://www.vents-sauvages.fr/bruicolage/placement-des-trous.html)
- C'est en projet qui doit être hébergé sur Github pages

## Normes

- Les noms de fonctions/variables représentent des intentions claires, pour une charge mentale minimale
- Pas de commit/merge sur main/master. Une feature = une branche
- Les Docstrings sont des one-liners
- Aucun fichier de travail (documents de design, plans de travail) ne doit être commité
- Conventional commits
- Les commits sont unitaires (un seul changement logique par commit) et incluent une description des changements pour faciliter la relecture
- Les PR sont créées par le tech lead

## Stack

- html
- tailwind css
- svelte 5 (typescript)
- pnpm
- eslint
